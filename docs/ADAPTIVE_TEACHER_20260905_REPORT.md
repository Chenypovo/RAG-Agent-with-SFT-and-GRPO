# Frozen 7B teacher replacement: E0 / E1 / E2

**结论：实验全部完成，代码、模型、候选选择、训练检查点和三组1,000题评测核验通过。新 SFT 改善了答案和证据指标；随后原定20-update GRPO减少检索，却损失准确率，并重新形成明显的两次检索停止倾向。不能声称已经彻底消除停止偏置。**

新 SFT 相对当前环境 Prompt-only 的 Answer EM 从43.9%提高到48.0%，Joint Success从36.6%提高到43.2%。GRPO将平均检索次数从3.512降至2.215（减少36.93%），但 Answer EM降至45.6%、Joint Success降至39.0%；两项下降的逐题配对95%区间均低于零。该负面结果按原协议保留，没有换seed、调reward或重跑。

## 实验分组与归因边界

| 分组 | 监督数据与训练 | 结果用途 |
|---|---|---|
| E0 历史 | fixed-two-hop scripted teacher；旧 SFT-v2 / GRPO | 原报告、数据和 checkpoint 保持原归因 |
| 新 Prompt-only | 未接入新 adapter 的 Qwen3-1.7B | 当前提示、检索栈、7B finaliser 下的新配对基线 |
| E1 | frozen 7B 候选轨迹 + Qwen3-1.7B QLoRA SFT | 与新 Prompt-only 和 E2 做同环境配对比较 |
| E2 | 从 E1 adapter 开始的原定20-update GRPO | 判断这次 GRPO 在新 SFT 基础上的实际变化 |

E0 的正式 hybrid+7B 评测中，7B 的角色是 finaliser；旧数字不能重新归因于 frozen 7B teacher。当前提示文本与历史不同，因此没有复用 E0 的 prompt-only 结果。E0 与新实验的比较仅作历史描述，不能把训练检索对齐、提示变化和 teacher 替换合并后归因为单一组件的因果增益。

## 固定协议与环境

- 所有测试、生成、训练、评测、指标计算及科学绘图均在单卡 AutoDL RTX5090D 完成。Mac 仅用于阅读、编辑、文件完整性检查、备份和查看图表。
- GPU 实测32,607 MiB；CUDA toolkit12.8.93；PyTorch2.8.0+cu128，包含 sm_120。Transformers4.57.6、Accelerate1.14.0、PEFT0.20.0、bitsandbytes0.50.0 均通过实际 GPU 检查。
- 真实兼容性测试在科学运行前完成：同一个冻结7B生成 teacher/finaliser 输出，并与实际 Qwen3 NF4 QLoRA 同时驻留，完成有限且非零梯度的反向传播及一次优化器更新。测试 adapter 未保存或用于训练。
- Qwen2.5-7B-Instruct revision：`a09a35458c702b33eeacc393d103063234e8bc28`。Teacher 和 finaliser 使用完全相同的本地模型路径、revision 与实例。
- Qwen3-1.7B revision：`70d244cc86ccca08cf5af4e1e306ecf908b1ad5e`。BGE embedding/reranker 的固定版本及全部模型文件哈希见模型清单。
- 复用现有 LanceDB dense + BM25 + RRF（k=60）+ BGE reranker，15个候选重排为6个句级结果。保持 supporting-fact 句子ID，不启用 parent-child expansion。
- Pilot：固定训练顺序前50题，每题最多2条候选，每条最多5个动作。完整生成：全部1,617题，每题最多4条候选，每条最多5个动作。Seed42；只允许 retrieve_docs 和 final_answer。
- 候选在完整结束后由原 verifier 选择；遇到 clean 且完整句级证据的候选后，可停止该题的后续候选采样。完整采样与 pilot 是预先规定的两个阶段，没有跨阶段挑选较好结果。
- Gold 不进入 controller prompt。完整审计验证了23,028个动作提示均与 observation-only renderer 相同，并重算了全部1,617次候选选择。检索文本自然包含答案不等于 gold 标签泄漏。
- 原 GRPO 的 reward、seed、128题训练池、20 updates、每次2题×4条 rollout、2个优化 epoch、学习率、clip 与 KL 设置均保持不变。

## SFT 与 GRPO 的实际训练结果

原 complete-evidence/clean-transition 筛选保留949条轨迹，生成4,541个样本：3,697个检索动作、844个显式停止动作，没有旧式 pre-stop 重复增强。过滤掉399条含重复调用的轨迹、103条含 invalid-action transition 的轨迹、1条解析失败轨迹和165条低于证据阈值的轨迹。

需明确保留两个限制：

1. 现有筛选器不要求每条轨迹以显式 final_answer 结束，因此105条“取得完整证据但耗尽预算”的轨迹仍进入 SFT。没有在观察到结果后改筛选规则或重训。
2. 由于 clean-transition 筛选，SFT 子集没有保留重复、空检索或失败检索的恢复示范。实际保留轨迹的81.77%使用4次及以上检索，平均3.896次；不能声称已获得全面的失败恢复训练。

QLoRA SFT 完成2 epochs、568个优化器步骤，训练损失0.1955。4,541个样本中749个提示在原2,048-token限制下被截断；保留 final adapter 与 checkpoint550/568，遵循原 save_total_limit=2 设置。

GRPO 完成20 updates、160 episodes、714个动作决策，113个提示在同一长度限制下被截断。全部训练数值有限，冻结参考 adapter 的前后哈希一致；全部20份完整恢复检查点哈希通过核验。最终 adapter 的392个张量与第20次更新检查点逐一完全一致。

## 失败、恢复与统计定义

- retrieve_docs 次数按动作尝试计，包括被拒绝的重复检索。旧汇总 MeanToolCalls 还会计入不存在的工具名，二者不能混用。
- 一些候选误把 final_answer 写成工具名，环境正确拒绝了它们。入选轨迹有165个此类动作和1个 JSON解析失败；真正的显式停止共有1,104次。原始报告保留，修正后的动作分类单独存于 integrity_audit.json。
- 入选轨迹有659次重复调用事件，125次随后取得新证据（18.97%），77次随后取得新证据且最终 Joint Success（11.68%）。其中444次还有后续动作机会。
- 全部候选有3,385次重复调用事件，710次随后取得新证据（20.97%），351次同时满足新证据与 endpoint Joint Success（10.37%）；2,203次有后续动作机会。分母是失败事件，不是不同题目的数量。
- 完整 teacher 中空检索与执行失败检索暴露均为0，恢复率为 unresolved / no exposure。没有实际暴露不能写成0%或100%的恢复能力。
- Contradictory retrieval 没有人工判定标签，恢复率保持 unresolved；没有新增干扰任务或自造检测器来补数字。
- Premature stop rate 是“显式停止且完整句级证据不足”的轨迹数除以全部轨迹数。JSON invalid rate 是严格解析/动作结构错误除以决策数；与工具是否存在、是否执行成功分别报告。

SFT提高答案质量的结论有本次配对数据支持。GRPO相对SFT则呈现明确的检索成本与准确率损失：平均调用少36.93%，但EM、F1、Joint Success和两项完整证据指标都下降。环境return只从0.51978升至0.52574，差值区间[−0.02444, 0.03655]跨零；不能据此证明reward目标改善，更不能认定某一个reward系数就是原因。本次没有reward消融。

## 固定两轮偏置：直接证据与最终判断

| 两次检索后的状态 | 新 Prompt-only | E1 SFT | E2 GRPO |
|---|---:|---:|---:|
| 证据不足时：停止/机会 | 0/368（0%） | 23/265（8.68%） | 140/241（58.09%） |
| 证据完整时：停止/机会 | 0/632（0%） | 82/733（11.19%） | 503/664（75.75%） |
| 证据不足时继续，之后取得完整证据 | 30/368 | 72/242 | 27/101 |
| 证据不足时继续，之后Joint Success | 14/368 | 41/242 | 14/101 |

这些gold完整性标签仅在整条轨迹结束后添加。新SFT有2题、GRPO有95题在一次检索后停止，没有进入“两次检索后的下一决策”分母。不同模型的条件分组题目可以不同，因此该表描述行为，不能当作“完整性对停止的因果影响”实验。

**目标分层判断：**

1. **固定两次检索的标签来源已替换。** E0 teacher的1,617条轨迹全部固定两次；新teacher与SFT数据已经出现2–5次变化，SFT评测也出现1–5次检索。
2. **新SFT明显摆脱了“多数题恰好两次”的表现，但尚未证明合理停止。** 仅10.5%的题恰好两次；证据不足时大多继续。不过四次检索占51.9%，证据完整时也经常继续，提示仍有长度偏好。
3. **最终GRPO没有真正消除两次检索依赖。** 64.3%的题恰好两次检索，证据仍不足时58.09%立即停止；提前停止从17.8%升至26.4%。不能把“允许1–4次”或“预算耗尽归零”当作目标已经成功。
4. **原因仍不能锁定。** 现有reward、短20-update训练、teacher长度分布、SFT筛选与上下文截断都可能有关；本实验没有分别干预，不能把相关现象写成已证实的原因。

停止行为审计保存9,676个“指定检索次数后的首次下一决策”记录。案例按各类task_id字典序选前两题，避免只挑成功样本：

- SFT继续检索的成功例：`hotpotqa_5a7633ff5542994ccc918712`，询问超音速地面车辆首席空气动力学家的出生年份；先查职位、再查Ron Ayers出生年，证据仍缺时继续查Thrust SSC/JCB Dieselmax，三次检索后回答1932，完整证据和Joint Success均成立。
- 适时停止的例子：`hotpotqa_5a71166d5542994082a3e576`，比较Manila与Guam战役日期。GRPO两次检索已取得完整证据，停止并答对；SFT对同题继续到四次后答对。说明两次停止本身并非错误。
- 提前停止的失败例：`hotpotqa_5a70f1685542994082a3e40f`，询问Beethoven献给Count Moritz von Fries的1801年作品。GRPO两次后在证据不完整时停止；SFT继续第三次检索，但仍失败。两者均输出Violin Sonata No.4，Joint Success为0；更多检索也不保证成功。
- 重复后恢复的例子：`hotpotqa_5a7521c55542993748c897c6`，GRPO重复查询Temagami-Lorrain后，改查Burwash Mine，最终获得完整证据并答对。此个案只证明出现过恢复，不证明普遍恢复能力。

## 成功、失败与结论边界

成功：统一了teacher、SFT轨迹与正式评测的检索栈；完成冻结teacher替换、全量数据与两阶段训练；每条候选、每个GRPO更新及全部3,000条评测轨迹均可审计；新SFT在当前匹配环境中提高了答案与证据指标。

失败：最终GRPO没有消除两次停止倾向；降低检索成本的同时损失了答案质量。未获得可验证的空检索、执行失败或矛盾检索恢复证据。

限制：单seed、复用benchmark/dev；teacher数据的4次/预算长度集中；105条无显式停止轨迹进入SFT；SFT与GRPO提示截断；恢复暴露不足；E0与新实验之间同时改变了teacher、训练检索环境及提示，不能进行单因素归因。未知或无暴露指标均明确标为unresolved/N/A，没有用额外试验补齐。


当前实验不支持以下结论：

- 已彻底消除两次停止偏置，或已学会全面合理的自适应停止。
- GRPO提高准确率，或在保持/等效/非劣准确率的情况下提高效率。
- 冻结7B teacher单独造成了E0到E1的全部变化；或把旧fixed-two-hop数字归到新teacher。
- GRPO造成了组合检索栈的全部准确率增益。
- 具有稳定、普遍的空/失败/矛盾检索恢复能力。
- 单seed结论稳定、具有独立测试集或多seed验证、达到SOTA或适用于任意多工具agent。
